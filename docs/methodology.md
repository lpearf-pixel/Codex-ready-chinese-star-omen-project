# Methodology（初稿）

## 1. 研究目标

建立可追溯、可校验、可回测的中国传统星占研究系统，而非直接复刻古代断语。

## 2. 基本立场

1. 以恒星实空位置为基础，不以西方黄道十二宫符号替代。
2. 古籍语言作为规则候选，而非无条件真理。
3. 所有输出必须携带来源、条件、限制与置信说明。
4. 任何重大结论不得跳过历史验证。

## 3. 观测与坐标原则

1. 内部统一 UTC。
2. 对外可转换北京时或指定地方时。
3. 记录观测地点影响可见性。
4. 内部默认 J2000，必要时转换历元。

## 4. 岁差与对齐原则

1. 古籍星位不可直接等同现代赤经赤纬。
2. 对齐过程记录文本年代与对齐版本。
3. 多套现代识别需保留并标置信度。
4. 岁差/历元转换集中于天文模块统一处理。

## 5. 术语阈值原则

1. `guarding`、`invading`、`conjunction`、`gathering`、`retrograde`、`stationary` 需独立阈值。
2. 阈值写入配置或文档，不硬编码散落。
3. 阈值应由回测持续迭代。

## 6. 两段式检索与证据回链

1. 第一段高召回：结构化卡片与索引层。
2. 第二段强制回证：`fenjuan` 或 `fulltext`。
3. 若无法回到 primary，仅可输出线索/候选解释。

## 7. 输出约束

1. 区分研究报告与推演报告。
2. 推演报告至少区分背景指标、触发指标、短期扰动指标。
3. 禁止单句绝对断言，必须包含不确定性说明。
